# 11. 영화적 활용과 변경을 검토할 설정

> 이 문서는 시놉시스를 **다시 쓰지 않는다**. 계산 결과가 시놉시스 v4(PDF p.4–8)의 어떤 설정과 맞고 어떤 설정과 충돌하는지, 작가가 선택해야 할 지점을 정리한다. 선택은 작가의 몫이다.

## 1. 반드시 결정해야 하는 연대 선택

이 경우 '춘궁기'는 1781년 봄이 되어, 1780년 봄 구휼(시놉시스 1막)과 사망 사이에 약 9개월 간격이 생긴다. 구휼–포폄–적대 형성–사망의 극적 연속성을 어떻게 메울지가 각본 과제다(1780 L12 포폄은 1780년 봄·여름 구휼 실적을 평가할 수 있다).

## 2. 인과구조 선택 — 대표 세계에서 얻는 시사점

[`06_world_comparison.md`](06_world_comparison.md)의 파레토 비지배 세계(W03·W05·W07·W09·W10)는 서로 우열이 없다. 작가 선택을 돕는 관찰만 적는다.

1. **경제적 인과성은 공짜가 아니다.** 윤씨의 거절을 '종자·양식을 위협하는 추가 요구'로 설명하려면 4개의 미입증 가정(일부 가구 식량 부족 E13, 상층 회피 E7, 조재항 회피 불가 E5, 추가 요구 > 가용량 E9)이 함께 필요하다. 비경제적 사유 하나로 대체하면 가정 수는 줄지만 '한 사발의 밥'이라는 제목의 경제적 핵심이 사라진다.
2. **강제 권분(늑분)은 모형상 필수 조건이 아니다.** 주민이 '관의 뜻'으로 출연을 요구하는 명분은 이가원의 선택적 정보 공개만으로도 생긴다(07 문서 Q3). 강압을 넣으면 권중립의 방어 동기가 강해지지만 가정이 하나 늘어난다. W07(자발적 권분 + 모든 설명 기준 충족)이 W01(시놉시스에 가장 가까운 강압 세계)을 지배하는 이유다. → 1780 배천의 강압은 사료가 없으므로, 강압의 주체를 이가원(단독)으로 둘지 권중립(인지)으로 둘지는 **극중 선택**이며 어느 쪽도 역사적 사실로 제시하면 안 된다.
3. **조상진의 은폐 동기는 포폄 인지 시점에 따라 책임의 종류가 바뀐다**(07 Q6): 사전 인지 → 평가의 공모적 왜곡 / 사후 인지 → 정정 의무 위반 / 감독책임 우려만 → 자기 보호형 부실 / 동기 없음 → 단순 과실. 실록이 기록한 것은 마지막 형태('직접 조사하지 않고 수령에게 맡김')에 가장 가깝다. 시놉시스의 '의도적 누락'은 앞의 세 형태 중 하나를 극중 설정으로 택하는 것이다.
4. **이가원이 살해범을 알 필요는 없다**(07 Q9). 사료의 무고 구조(사후 금품 요구 → 거절 → 조환 사주 → 농요)는 그것만으로 성옥까지 간다. 사전 관여는 사료의 '사후 무고' 서술을 넘는 창작이므로, 넣는다면 반전 장치로서 명시적 각색이어야 한다.
5. **조환의 사주 수용**: 조환이 조재항을 신뢰했다면 이가원은 언쟁 정보만으로는 부족하고 '추가 증거'(가장된 목격담 등)가 필요하다(07 Q7). 실록의 '피 묻은 옷의 행방 없음'(CL-SIL-05)은 이런 가짜 증거의 흔적으로 극화할 수 있으나, 혈의가 누구의 주장이었는지는 원문 확인 전까지 단정하지 않는다.
6. **복검이 바로잡았다면 장기 구금은 없다**(07 Q10). 이우배의 실패 이유를 '같은 진술원에 기댄 것'(정보 독립성 결여)으로 둘지 '검증 소홀'로 둘지는 수사극의 주제("반복 검증 ≠ 독립 검증")와 직결된다. 진술원 공유 쪽이 3사례 비교 보고서의 조재항 사건 논지와 더 잘 맞는다.

## 3. 자막·부록에 반드시 밝힐 각색

- 연대: 성옥 연대 채택 근거(심리록 1780 vs 실록 1781)와 압축한 날짜 목록.
- 포폄: 조상진의 권중립 포폄·등급·근거는 사료 미확인 → 극중 설정.
- 권분: 1780년 배천 권분·강압·조재항 출연량 → 극중 설정(제도적 선례만 확인).
- 살해: 주민 살해·살해범·장소·시신 이동 → 창작.
- 조사: 암행어사 파견·이득준 사관·고의적 보고 누락 → 창작. 실록은 조상진의 '직접 조사 없음'만 비판.
- 처벌: 살해범 처형, 권중립 삭거사판, 이우배 유배, 조상진 나문·정배, 은 10냥 → 창작(실제는 방면·이가원 정배·조상진 파직·기타 경중 처벌 명령).

## 4. 역사적 인물에 대한 서술 원칙

권중립·이우배·조상진·이가원·조환은 실존 인물이다. 이 분석의 어떤 세계도 그들의 실제 동기를 입증하지 않는다. 사료가 기록한 것은 (판부 속 판단으로서) 이가원의 무고·농요 조작, 조상진의 비직접 재조사, 초·복검이 혐의를 바로잡지 못한 결과까지다. 그 너머의 악의·공모·은폐 동기는 극중 해석으로 표시해야 한다.
