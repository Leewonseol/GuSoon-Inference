## 기획의도

광주 여고생 살인 사건의 증거 은폐 의혹과 화성 8차 사건에서 윤성여가 겪은 누명은 서로 다른 방향에서 같은 질문을 던진다. 국가는 범죄자를 처벌하는 동시에 무고한 사람을 보호하고, 검증의 오류를 바로잡을 수 있는가?

1793년 정조는 구순의 도난 사건과 김명신의 죽음을 둘러싼 상반된 보고를 그대로 받아들이지 않고, 별도의 안핵어사를 파견해 사건을 다시 조사했다. 기존의 판단을 뒤집고, 무고한 사람을 범죄자로 몰아간 자들과 수사 책임자들에게 책임을 물었다.

이 작품은 조선의 한 형사사건을 통해 묻고자 한다. 민주주의도, 오늘날과 같은 과학수사 기술도 없었던 시대에조차 사건을 거듭 검증하려 했다면, 더 자유롭고 과학기술이 발달한 오늘날에는 왜 피해자와 무고한 사람이 스스로 진실을 입증하기 위해 싸워야 하는가?

본 조선 수사극은 사건의 진위 여부를 가리는 검증 과정을 추적한다.
