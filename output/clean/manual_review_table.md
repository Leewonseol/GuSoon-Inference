# 수동 검토표

현재 build 결과(동결 hash `005d4b7df030…`)를 사람이 판단하기 쉽게 정리한 표다.
사용자가 확정한 ID01·ID02·ID03·ID11만 반영했고, 그 밖의 역사적 판단은 새로 넣지 않았다.

- **A**에는 이미 확정된 동일성을 모았다. 선택 칸이 없다.
- **B**에는 지금 결정하면 모델 결과가 바뀌는 항목만 모았다. 선택 칸이 있다.
- **C**는 참고용이다. 결정해도 결과가 바뀌지 않으므로 선택 칸이 없다.
- **D**는 HIGH LATENT 후보, **E**는 narrative world 비교다.

ID 표기: `CFxxx`는 confirmed fact, `EPxx`는 episode node, `OExxx`는 edge, `Gxx`는 gap, `Gxxa`는 latent 후보, `Wx`는 world다.
